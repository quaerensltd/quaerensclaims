# Energy Supplier Complaint & Switching Pack Builder

Part 1A local implementation for `public/energy-switch.html`.

Status: native QCBF-style builder shell awaiting Part 1B and Part 2.

This implementation covers:

- first-question branching;
- consumer, property, account, supplier, tariff and meter fields;
- switching, billing, metering, payment, credit, moving-home, tariff, vulnerability and complaint-history paths;
- urgent safety and court boundary warnings;
- cautious jurisdiction and account-scope warnings;
- dynamic evidence recommendations;
- route analysis;
- context-aware missing wording;
- core preview document logic.

It intentionally does not complete exports, Smart Submission, Ofgem verification, automatic compensation, Energy Ombudsman deadline logic, supplier directories, SEO freeze or production deployment.
