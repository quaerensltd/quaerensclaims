# Free Rail Journey Disruption & Compensation Builder

Native QCBF builder ID: `train`

This is the Phase 1 foundation build. It creates the issue-led rail journey builder structure, dynamic journey analysis, evidence position, financial schedules, pack reference, draft storage and preview cards.

Phase 1 deliberately does not implement:

- PDF export
- Word/RTF export
- TXT export
- Print
- Copy
- Smart Submission
- FAQ
- SEO polish
- Deployment polish

Those items belong to Phase 2.
