# Framework A v1.6 Category Adapter Certification

Framework A v1.6 adds a backward-compatible, allow-listed Category Adapter Contract and migrates Car Finance and Cruise Compensation to the single shared shell, preview and output runtime.

Allowed hooks cover derived calculations, quality/completion rules, analysis, complaint and email wording, twelve-page content, cover metadata and file labels. No hook exists for UI mounting, navigation, chronology/evidence rendering, preview rendering, output generation, metrics transport or Framework C handoff.

Car Finance preserves its lender, dealer, agreement, vehicle, PCP/HP, finance figures, commission, suitability, sales, response, arithmetic and cautious redress depth. Cruise preserves its operator, ship, organiser/intermediary, booking, itinerary, missed-port, delay, boarding, cabin, hygiene, accessibility, facilities, excursion, baggage, charge, refund and financial depth.

Both routes inherit Applicant Details, Unique Complaint Pack Reference, Evidence Readiness, Complaint Pack Quality, Help the Next Person, Anonymous Platform Metrics and the separate Framework C boundary.

Legacy category source modules remain as regression and rollback/reference material but are not imported by public routes. The Car Finance inline wizard/document generator and Cruise controller/private preview/document imports are retired from public HTML.

Local acceptance recorded: adapter allow-list tests, shared QCBF regression, both category suites, all seven Framework A routes with twelve pages, Applicant Details, metrics, no legacy mount and no horizontal overflow.

Production deployment and live acceptance must be appended before this is treated as the final live production record.

## Complex-category layout refinement

Car Finance certifies the backward-compatible declarative `complex` presentation profile. The profile is selected in category configuration and consumed generically by the shared runtime. It provides a wider desktop form column, reusable field-span metadata and grouped question headings while retaining the single shared workflow, preview, twelve-page document model, output engines, accessibility behaviour and responsive shell. Every other certified category continues to default to the unchanged `standard` profile. No URL, builder-name or Car Finance presentation branch exists in the runtime.
